Detailed Description

What the game remembers between runs: last table and players.

Kept in state.yaml in the user state directory ($XDG_STATE_HOME/royalcraps, usually ~/.local/state/royalcraps). The game writes it at quit. It is never shipped, and its absence is normal.

last:
table: las-vegas-strip.yaml
userPlayer: arthur.yaml
buddyPlayers:
- paige.yaml
- nathan.yaml
settings:
animationSpeed: fast
rollHistoryFormat: 2

The settings section is optional. A setting in it is only used when config.yaml does not state that setting.

state.yaml is only a memory. It says what happened last time and it does not override anything the user wrote in config.yaml; see StartChoices for how the two combine. This class only reads and writes the file. It does not check that the files named exist, which is StartChoices' job, because what to do about a missing file depends on where the name came from.

load() never throws. A state file that can't be parsed or is missing its sections is reported in the log and treated as absent.
