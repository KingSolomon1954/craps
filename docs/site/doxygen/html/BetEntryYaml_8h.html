Detailed Description

Shared YAML form of LastFill, AutoFill and QuickBet entries.

Those three classes each hold a list of entries with the same four fields. This is the one place that knows how such a list looks in a player file, so the three cannot drift apart:

- betName: PassLine
pivot: 0
isOddsBet: false
amount: 50
