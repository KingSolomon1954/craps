Detailed Description

Saves the bet being entered into a QuickBets entry.

Offered from DialogBetAmount. The first choice makes a new entry holding this bet. The others add the bet to one of the player's existing entries, each with a letter. When there are more entries than fit, the Up and Down keys scroll the list; the letters always pick by position in the whole list.

┌──────────────────────────────────────────┐
│ QuickBets Set or Add (Place bet 6 $24) │
├──────────────────────────────────────────┤
│ [1] Set as new QuickBets entry │
├──────────────────────────────────────────┤
│ Add to an existing entry: │
│ [a] Place Hi | Place 8 $24, Place 9 ... │
│ [b] Place Lo | Place 4 $20, Place 5 ... │
│ [. or esc] Back │
└──────────────────────────────────────────┘
BetName::Place
@ Place
Place bet.

The dialog pops itself and reports to OperationManager::onQuickBetsChoice().
