Detailed Description

Manipulates Money.

Has these capabilities:

  • Internal storage in int64_t cents_
  • Whole-dollar convenience functions
  • YAML serialization
  • Flexible operator<< formatting using custom I/O manipulators: 
        Show/hide dollar sign: showDollar, noDollar

    Show/hide cents: showCents, noCents

Eample usages:

Money bet = Money::fromDollars(25.50);
Money win = Money::fromWholeDollars(100);
// Default format
std::cout << bet << "\n"; // $25.50
// No cents
std::cout << showDollar << noCents << bet << "\n"; // $25
// No dollar sign
std::cout << noDollar << showCents << win << "\n"; // 100.00
// Raw cents
std::cout << "Stored as: " << bet.toCents() << " cents\n"; // 2550
// YAML
YAML::Node node = win.toYAML();
Money restored;
restored.fromYAML(node);
std::cout << "Restored: " << restored << "\n";

Convert to string with formatting options.

Have to supply all three options.

Example usage:

Money m = Money::fromDollars(1234.56);
std::cout << m.toString(); // "$1,234.56"
std::cout << m.toString(noDollar, showCents, showComma); // "1,234.56"
std::cout << m.toString(showDollar, noCents, showComma); // "$1,234"
