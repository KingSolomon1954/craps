Detailed Description

Turns a list of bet specs into bets for one player.

The one place that applies QuickBets, and later AutoOdds and buddy automation. Each placement uses Player::makeOrChangeBet() and Player::setOddsAmount(), the same as a bet request from the View, so the table's rules, limits and funds checks apply unchanged and the usual bet and balance events follow.

A player has one bet per spot, so a spec for a spot that is occupied sets that bet's amount. A spec whose amount is already there changes nothing and is not recorded for undo. All the changes made by one call are a single undo step.

The caller checks that betting is open; if it is not, every spec is refused by the table and comes back skipped with the table's reason.

Not a singleton and holds no state of its own. It records undo steps with UndoManager::instance(). Tests give it a Player directly.

Member Function Documentation

◆ apply()

BetExecutor::Result BetExecutor::apply ( Craps::Player & player,
const std::vector< BetSpec > & specs,
LastFill * lastFill = nullptr )
static

Applies the specs for the player, best effort: a spec that cannot be placed is skipped and the rest go on. Contract bets are applied before odds bets, whatever the order given. Everything applied is one step for undo, recorded with UndoManager::instance(). lastFill, if given, is updated as for a bet the player placed by hand.
