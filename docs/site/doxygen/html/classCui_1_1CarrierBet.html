Detailed Description

Static bet object filled in by a chain of menus.

A single static object shared by menu classes involved in betting.

Top level betting menus are responsible for clearing the CarrierBet upon activation and then each child menu fills in their betting information. At the very end of the chain the CarrierBet holds all information needed to make a bet.
