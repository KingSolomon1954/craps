Detailed Description

Controller Library (lib-controller)

This library is the "Controller" in the Model/View/Controller (MVC) design paradigm. It has several major responsibilities:

  • performs game initialization and shutdown
  • provides an abstraction layer between the Model (lib-craps) and the CUI (lib-cui) and GUI (lib-gui)
  • controls game operations, events, configuration, etc

Typedef Documentation

◆ CorrelationId

using Ctrl::CorrelationId = std::uint64_t

An ID to match Response Events to Request Events.

Every event carries a correlationId allowing users to match up Requests with Responses. By default, and for convenience, a correlationId is set to the uniqueId. In the case of Response Events, the caller is responsible for overwriting the correlationId with the source event's correlationId.

◆ EventSource

enum class Ctrl::EventSource
strong

The source of an Event.

The source aligns with the Model/View/Controller (MVC) design where:

  • Model = the event came from the Craps Engine (lib-craps)
  • View = the event came from the CUI (lib-cui) or GUI (lib-gui)
  • Controller = the event came from the Controlloer (lib-controller)
