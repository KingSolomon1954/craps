Detailed Description

Controller Library (lib-controller)

This library is the "Controller" in the Model/View/Controller (MVC) design paradigm. It has several major responsibilities:

  • performs game initialization and shutdown
  • provides an abstraction layer between the Model (lib-craps) and the CUI (lib-cui) and GUI (lib-gui)
  • controls game operations, events, configuration, etc
