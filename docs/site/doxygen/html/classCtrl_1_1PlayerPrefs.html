Detailed Description

One player's controller-level preferences.

Things the controller remembers for a player that the Craps model knows nothing about: LastFill, QuickBets and AutoOdds, which are plain data, and what the buddies do when the player changes tables (BuddyFollow). To add another, add a member here and a key in toYAML() and fromYAML().

PlayerManager owns one PlayerPrefs per player. Observers reach the user's through PlayerManager::userPrefs(). Nothing here is a singleton, so changing who the user is just changes which PlayerPrefs is returned.

Persistence: toYAML() produces the player file's "Prefs" section and fromYAML() restores from it. fromYAML() is forgiving; a missing or malformed section yields empty preferences and never throws.

Prefs:
LastFills:
- betName: PassLine
pivot: 0
isOddsBet: false
amount: 50
QuickBets: [...] # see QuickBets.h
AutoOdds: {...} # see AutoOdds.h
BuddiesFollow: follow # follow, stay or ask; see BuddyFollow.h
