Detailed Description

Display diagnostic in a pop up, user must acknowledege.

Caller must call configure before pushing dialog to SurfaceManager. The dialog displays several sections some of which are optional depending on the configuration.

  • Title bar always shows "Error", followed by ErrorType, and ErrorName. ErrorType and ErrorName can never be empty.
  • Section Description, always shows supplied text
  • Section Probable cause appears only if non-empty
  • Section Proposed repair appears only if non-empty
  • Section additional info appears only if non-empty
  • Section Trace appears only if a programmatic type error

Member Function Documentation

◆ configure()

void DialogError::configure ( const Gen::ErrorPass & ep)

Caller provides what is to be displayed.

This call populates ErrorText from ErrorPass.

Upon return, ErrorText is formatted and ready to be drawn.

ErrorText structure knows the number of sections to be drawn. Each section is already formatted (wrapped as necessary), max rows and cols of each section are known. winPos_ and winSize_ have been updated.
