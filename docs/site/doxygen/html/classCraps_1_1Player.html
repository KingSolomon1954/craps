Detailed Description

Craps player.

Player Responsibilities:

  • Maintains player's money
  • Tracks player's bets
  • A player has at most one bet per spot, as at a real table where the chips stack up. makeOrChangeBet() makes a bet, or if the player already has that bet changes its amount to the amount given. It is the only way to place a bet. makeBet() is private; unit tests that need a bet that is always new use testMakeBet().
  • Exports its own state with toYAML() and restores it with fromYAML()
  • Knows nothing about files, paths or where that YAML is stored. Lib-controller's PlayerManager owns each player's file and decides when to read and write it.
  • endSession() ends the player's session: leaves the table, records the session summary, merges stats. It writes nothing to disk. Call toYAML() and persist it afterward. The player can then join a table again, which starts a fresh session (new stats, new session clock, the balance carries over). shutdown() is endSession() at program quit.

◆ leaveTable()

zeus::expected< void, Gen::ErrorPass > Player::leaveTable ( )

Player leaves the table.

Any outstanding bets on the table are forcibly removed, meaning bets are pulled from the table and funds are returned to the player. This bypasses normal table checks that prevent removing bets due to Craps table rules.

UI should perform confirmation checks with users prior to leaving table.

leaveTable() is called upon program shutdown as well as when player switches tables.

Returns
Success, otherwsie Fail and ep has the reason for failure. It is not an error if a player has not joined a table.

◆ makeOrChangeBet()

zeus::expected< Player::BetPlaced, Gen::ErrorPass > Player::makeOrChangeBet ( BetName betName,
Gen::Money contractAmount,
unsigned pivot )

Makes a bet, or if the player already has that bet, changes its amount.

A player has at most one bet on a given spot, as at a real table where the chips stack up. Asking for the same bet again is a request to make it the given amount, not to add a second bet. Nothing is added to the existing amount; repeating a request gives the same result.

  • findBet() decides whether it is the same bet.
  • Not there: same as makeBet().
  • There: same as setContractAmount(), including its rules, such as no reducing a PassLine bet and no increasing a DontPass bet after the point, and the table limits applied to the new amount.
  • Already that amount: nothing to do, still a success.
Parameters
[in]betNameThe bet
[in]contractAmountThe amount the bet is to be, not an amount to add
[in]pivotAs for makeBet()
Returns
The bet, whether it was changed, and its previous amount if so. Otherwise Fail and ep has the reason.

◆ recordRepeaters()

void Player::recordRepeaters ( unsigned point,
unsigned roll,
const std::list< DecisionRecord > & drl )

Record what this player took part in for the Repeaters statistics.

Called by CrapsTable for every player on every roll, before results are dispensed, so the bets are still on the table. point is the point as it was when the dice were thrown and drl holds this roll's decisions for all players.

A hit of a point number counts when the player had a live bet on it:

  • Pass line or Come bet whose number is rolled, including the roll that establishes the number. One hit per roll, even when several of the player's bets are on the number.
  • Place or Buy bet that wins on the number.

A seven ends the run for Pass line and Come numbers. A seven out ends the run for Place and Buy numbers; a come out seven does not, since those bets are off. See closeSpotRepeaters().

◆ setOddsAmount()

zeus::expected< void, Gen::ErrorPass > Player::setOddsAmount ( BetPtr pBet,
Gen::Money newAmount )

Sets, changes, or removes the amount for an odds bet.

Overwrites the previous amount, if any. A value of zero removes it altogether.

It is only permissable to set an odds amount if the following conditions are true:

  • the bet is already on the table
  • the bet is a PassLine, DontPass, Come, or DontCome bet
  • the bet has an assigned pivot (point) (i.e, pivot is non-zero)
  • the new amount is subject to table limits min/max odds
Parameters
[in,out]pBetThe bet of interest.
[in]oddsAmountThe amount to set it to. Clobbers any previous setting.
Returns
ErrorPass object if an error occured, otherwise no error.
