Detailed Description

Manages last fill amounts for bets.

The LastFill class in controller has these responsibilities:

  • remembers the last amount used by a particular bet type in std::vector
  • setLastFill() - replaces amount if the entry already exists
  • getLastFill() - returns the amount used last time for a particular bet
  • getLastFills() - returns the read-only vector of last fill entries
  • deleteLastFill() - shift entries if necessary, no empty slots
  • clear() - forgets all entries, e.g. before loading another player's
Ownership and persistence

Not a singleton. Each player has one, held in PlayerPrefs, which PlayerManager owns. The View and EventHandler reach the right one through PlayerManager.

toYAML() and fromYAML() convert between the entries and a YAML sequence. The class does not touch files; PlayerPrefs puts the sequence under "LastFills" in the player file's "Prefs" section. fromYAML() replaces the current contents and is forgiving: a missing or malformed sequence, or an individual bad entry, is logged and skipped so a hand-edited player file can never stop the game from starting.
