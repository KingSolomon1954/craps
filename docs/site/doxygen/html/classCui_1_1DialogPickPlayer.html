Detailed Description

Shows a short list of players, optionally to pick one.

Each line is the name, an optional note, then a vertical bar and the short description, aligned on the bar and clipped to keep the dialog within 80 columns.

Pick mode: Up/Down move, Enter chooses, 1-9 chooses that line, Esc cancels. Show mode: the same list for looking only; Enter or Esc closes it.

The dialog pops itself and reports to OperationManager::onPickResult(). The list scrolls when there are more than eight players.
