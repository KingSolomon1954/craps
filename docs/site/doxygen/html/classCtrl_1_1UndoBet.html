Detailed Description

One undoable change to a bet, and how to take it back.

Each remembers what is needed to put things back and does that through the same Player and table paths as any other change, so the money, the house bank, the player's bets and the events that update the screens all follow. Undo does not repeat the rules for making or changing a bet: the change was allowed once and undo restores the earlier, allowed, state. It only needs betting to be open and the money to be there.

  • UndoBetAdded: a new bet was placed
  • UndoBetModifiedAmount: contract or odds amount changed
  • UndoBetRemoved: a bet was taken down
  • UndoBetFlagsChanged: the flags of a bet changed
  • UndoGroup: several of these as one step

See UndoManager for the stack, who owns it and when it is cleared.
