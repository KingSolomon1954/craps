Detailed Description

Provides an asynchronous thread safe Pub/Sub Event Bus.

Important behaviors:

  • publish() copies the event into a thread-safe queue and returns without running handlers.
  • A private worker thread removes events and dispatches them.
  • The subscriber map and event queue are protected by the same mutex.
  • Handlers are copied while locked but invoked after unlocking.
  • Events already queued are dispatched before the destructor finishes.
  • This version has no unsubscribe mechanism; subscriptions remain active for the lifetime of the manager.
  • Handler callbacks execute serially on the single worker thread. If one callback blocks, later events wait.
  1. Example: Unnamed subscriber callback function

@code struct DiceRolled { int value; };

Craps::EventManager events;

events.subscribe<DiceRolled>( [](const DiceRolled& event) { This runs on EventManager's worker thread. std::cout << "Rolled: " << event.value << '
'; });

events.publish(DiceRolled{6});

  1. Example: Named subscriber callback function

There are times you want to subscribe and dispatch to a named function within the source file.

Define a named function whose parameter matches the event type Then subscribe it using its address

void handleDiceRolled(const DiceRolled& event)
{
std::cout << "Rolled: " << event.value << '\n';
}
events.subscribe<DiceRolled>(&handleDiceRolled);
  1. Example: Using std::function()

A function pointer converts to the std::function<void(const DiceRolled&)> parameter automatically. So You can also write the equivalent with an explicit std::function: cpp

events.subscribe<DiceRolled>(
std::function<void(const DiceRolled&)>{handleDiceRolled});
  1. Example: For a function declared in another source file

Place its declaration in a header:

// DiceHandlers.h
#pragma once
void handleDiceRolled(const DiceRolled& event);

Define it in a .cpp file:

// DiceHandlers.cpp
#include "DiceHandlers.h"
#include <iostream>
void handleDiceRolled(const DiceRolled& event)
{
std::cout << "Rolled: " << event.value << '\n';
}

Then subscribe normally:

#include "DiceHandlers.h"
Gen::EventManager events;
events.subscribe<DiceRolled>(&handleDiceRolled);

  1. Example: For a non-static member function

Use a lambda that captures the object:

class Game
{
public:
void onDiceRolled(const DiceRolled& event)
{
std::cout << "Game received: " << event.value << '\n';
}
};
Game game;
events.subscribe<DiceRolled>(
[&game](const DiceRolled& event)
{
game.onDiceRolled(event);
});

Because EventManager stores the handler until it is destroyed, game must remain alive for as long as the subscription can be invoked. A safer option is to capture a std::weak_ptr when the receiving object is managed by std::shared_ptr:

class Game
{
public:
void onDiceRolled(const DiceRolled& event)
{
std::cout << "Game received: " << event.value << '\n';
}
};
auto game = std::make_shared<Game>();
std::weak_ptr<Game> weakGame = game;
events.subscribe<DiceRolled>(
[weakGame](const DiceRolled& event)
{
if (auto game = weakGame.lock())
{
game->onDiceRolled(event);
}
});
