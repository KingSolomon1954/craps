Detailed Description

Choose which bets to turn off or on.

Offers one line per kind of bet the player has that can take a flag (odds, place, buy, lay, hardway), plus all bets and one individual bet. Kinds the player has no bets for are not shown, so the menu is built each time it opens. The keys are mnemonic: i, a, o, p, b, l, h.

Picking a line starts the Bet Flags workflow in OperationManager.
