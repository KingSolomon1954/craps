Detailed Description

Display diagnostic in a pop up, required user to enter or ok.

There is no result to obtain. When the user presses a key the dialog is done.

Responsibilities of DialogAckError:

  • Key bindings for the dialog box
  • Process input keys
  • Takes action on input keys
  • Renders the dialog on screen
  • Function to establish message in dialog box
