Detailed Description

The View's memory of recent rolls, newest first.

  • Shared by WindowRollHistory (a row at the top of the screen) and DeepRollHistory (a popup of the last Capacity rolls).
  • Holds the rolls with their colors' flags, which the model does not keep.
  • Not a game rule: it is only what the View has seen since it started.
