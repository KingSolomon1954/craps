Detailed Description

Common abstraction for anything occupying a visible/input surface.

  • Provides a generic UI surface contract
  • Allow SurfaceManager to work with just surface abstractions
  • Has no knowledge of ScreenBase, MenuBase, DialogBase or PanelBase
