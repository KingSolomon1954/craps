Detailed Description

Manages auto fill amounts for bets.

The AutoFill class in controller has these responsibilities:

  • maintains a list of auto fill bets in std::vector
  • setAutoFill() - replaces amount if the entry already exists, zero is valid amount
  • getAutoFills() - returns the read-only vector of auto fill entries
  • deleteAutoFill() - shift entries if necessary, no empty slots
  • clear() - forgets all entries
Ownership and persistence

Not a singleton, and it publishes no events; it is plain data. Each player has one, held in PlayerPrefs, which PlayerManager owns. EventHandler changes the user's AutoFill and publishes UslAutoFillChanged.

toYAML() and fromYAML() convert between the entries and a YAML sequence, in order (see BetEntryYaml.h). PlayerPrefs puts it under "AutoFills" in the player file's "Prefs" section. fromYAML() replaces the current contents and never throws; bad entries are logged and skipped.
