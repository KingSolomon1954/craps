Detailed Description

Manages auto fill amounts for bets.

The AutoFill class in controller has these responsibilities:

  • maintains a list of auto fill bets in std::vector
  • setAutoFill() - replaces amount if the entry already exists, zero is valid amount
  • getAutoFills() - returns the read-only vector of auto fill entries
  • deleteAutoFill() - shift entries if necessary, no empty slots
