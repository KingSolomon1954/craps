Detailed Description

A player's named bundles of bets.

Plain data, one per player, held in PlayerPrefs. It does not place bets; BetExecutor does. A bad or missing section in a player file gives an empty list, never an error.

QuickBets:
- name: Place Hi
bets:
- { betName: Place, pivot: 8, amount: 24 }
- { betName: Place, pivot: 9, amount: 20 }
- name: Line with odds
bets:
- { betName: PassLine, amount: 10 }
- { betName: PassLine, isOdds: true, amount: 30 }

◆ tidy()

BetPlan QuickBets::tidy ( BetPlan plan)
static

What a plan must be to be kept, so that applying one never meets nonsense. Drops bets with no or invalid bet name, a zero amount, or odds on a bet that cannot be in a plan. A later bet for the same spot replaces the earlier. Keeps at most MaxSpecsPerEntry. Contract bets come before odds bets, otherwise order is kept.
