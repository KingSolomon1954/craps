Detailed Description

Signal Handling capability.

Meant for multi-threaded applications. Sets up an intiial signal mask so that spawned threads inherit the mask and block signals. Provides a waitForTerminate() function that unblocks selected signals and waits for one to arrive.

◆ SignalHandler()

SignalHandler::SignalHandler ( )

Constructor.

Upon construction sets up the initial global signal mask. For this reason this object should be constructed early, before any threads are created, so that new threads will inherit the proper per-thread signal mask.

◆ terminate()

void SignalHandler::terminate ( )

Causes the signal handler loop to release and exit its infinite loop. This implementation sends a signal to the signal catching thread to cause it to wake it up and exit.

◆ waitForTerminate()

void SignalHandler::waitForTerminate ( )

Blocks the calling thread and explicitly waits for a hard coded set of signals. When a signal of interest arrives it takes action, which usually means the loop exits. We're only looking for signals that should cause the program to exit and ignores all others. See the code for the set of signals.
