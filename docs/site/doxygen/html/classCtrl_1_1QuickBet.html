Detailed Description

Manages automatic bets.

The QuickBet class in controller has these responsibilities:

  • Maintains a list of quick bets in a std::vector
  • applyQuickBet() - makes the bet
  • setQuickBet() - replaces a quick bet if the entry already exists, zero is valid amount
  • getQuickBets() - returns the read-only vector of quick bet entries
  • deleteQuickBet() - delete an entry, shift entries if necessary, no empty slots
