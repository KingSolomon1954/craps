    Detailed Description

    Receives application GameEvents.

    Receives application GameEvents and converts them into work orders for the CuiThread.

    Responsibilities of CuiReceiver:

    • Event handler for GameEvents the CUI is interested in
    • Is the interface between the Controller's view vocabulary and the CUI's surface vocabulary.
    • Subscribes to Controller::EventManager
    • Converts events into work orders and enqueues the work order to the CuiThread for processing.
