Detailed Description

Popup listing the last 120 rolls, most detailed format only.

  • Reads RollLog; keeps nothing of its own.
  • Rolls keep the colors the roll history uses: seven out, pass line winner and point established.
  • Does not depend on any menu. Whatever menu offers it calls show().
