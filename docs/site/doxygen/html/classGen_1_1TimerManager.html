Detailed Description

Timers, managed with a single thread.

  • Multiple timers.
  • Each timer managed by its own unique ID.
  • Repeating timers re-arm themselves.
  • Can create timers immediately armed (createTimer).
  • Can create timers without arming them (createTimer).
  • Arm them later with armTimer().
  • Cancel or restart Timer at any point.
  • All timers run on a dedicated thread.
  • All operations are thread-safe.
