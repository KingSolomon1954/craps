Detailed Description

Manages undo operations on bets.

Supported (stack-based undo, limited to bets)

  • Scope: only bet state (no configuration, no gameplay state, no rolls).
  • Granularity: one atomic bet change = one undo step.
  • Kinds of changes:
  • new bet placed
  • existing bet modified (amount, odds, flags)
  • bet removed
  • Ordering: last-in, first-out (classic undo stack).
  • Lifetime: undo history is cleared after each roll (so you can only undo the current betting decisions before the dice are rolled).

Not supported (explicit exclusions)

  • Undoing out of order changes (no random-access undo).
  • Redo.
  • Anything outside of bets (like table config, game options).
