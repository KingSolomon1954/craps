Detailed Description

Craps Table Screen.

  • owns size of each Panel (in LayoutCrapsScreen)
  • relationship between Panels
  • screen-level borders
  • screen-level junctions
  • overall composition of its Panels
  • does not perform key input. MenuBetting does that.
