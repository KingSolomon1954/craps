Detailed Description

UI builds and enqueues an Event to perform against the model.

A collection of functions that builds and enqueues GameEvents to perform a command on the model. These are commands that change the game state.

See class CrapsInterfaceReader for read-only retrieval of information from the model.

Both GUI and CUI go through this interface.
