Detailed Description

Managers players.

Manages players.

Maintains a central index file (e.g., players/index.json) listing all known player IDs and names for fast access/UI.

PlayerManager Responsibilities:

  • Maintain list of player IDs
  • Load/save players from disk
  • Create new player
  • Choose active player
  • Use Player::serialize() and Player::deserialize() for actual data
