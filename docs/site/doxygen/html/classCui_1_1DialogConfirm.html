Detailed Description

Confirmation dialog for yes/no/cancel operations.

The dialog accepts:

  • Y/y - Yes
  • N/n - No
  • Esc - Cancel

The dialog is configured with a caller-supplied message, for example:

DialogConfirm::instance().configure(
"Confirm Quit RoyalCraps game");
