Detailed Description

Obtains bet amount from user.

DialogBetAmount prompts the player to enter an amount for a given bet. The dialog is first "configured" before pushing to SurfaceManager, similar to other menus and dialogs.

DialogBetAmount has some special behaviors. Since it is already focused on a particular bet and amount, it is natural to use it to help configure some automatic behaviors.

DialogBetAmount will support two menu entries such that if selected it uses the current entry value for:

  • Setting the auto fill value for the current bet type, to be used for default filling future bets of this type with the given amount.
  • Using the current bet type and amount to configure a Quick Bet. A quick bet is shortcut that is assigned to a particular bet and amount, and is given a fixed menu entry on the QuickBet menu. So for example, the user presses 'q' (quick bet menu) followed by 'a' (the first configured quick bet) could mean make a Place Bet on the 6 for 100.

Responsibilities:

  • Key bindings for the menu
  • Process input keys
  • Takes action on input keys
  • Renders the dialog on screen
  • Functions to establish defaults and fill values
