Detailed Description

Base class for all Events.

There are three categories of Events:

  • Request Events (prefix Req) - requesting some action be taken
  • Response Events (prefix Rsp) - response to a request
  • Unsolicited Events (prefix Usl) - something of interest happened

There are three Sources of Events, aligned with the Model/View/Controller design (See Ctrl::EventSource):

  • Model - The Craps engine
  • View - The CUI or GUI
  • Controller - The Controller

Unique ID (See Ctrl::EventId):

Every event gets a globally unique value for unique ID.

Correlation ID (See Ctrl::CorrelationId):

Every event also carries a correlationId allowing users to match up Requests with Responses. By default, for convenience, the correlationId is set to the uniqueId. In the case of Response Events, the caller is responsible for overwriting the correlationId with the source event's correlationId.
