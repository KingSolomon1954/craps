Detailed Description

Manages the active CUI surface stack and surface lifecycle.

  • Maintains the active surface stack
  • Manages surface attach, detach, pause, and resume operations
  • Coordinates surface placement through LocationManager
  • Creates and releases ncurses windows for surfaces
  • Dispatches keyboard input to the active surface
  • Redraws the complete current surface composition
  • Manages ncurses resource shutdown
