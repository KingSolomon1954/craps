Detailed Description

Decides where a new window rectangle should go.

Using already registered rectangles, LocationManager decides where a new rectangle should go.

  • knows screen dimensions
  • knows rectangles of active surfaces
  • finds best position
  • reserves successful position
  • releases position when surface disappears

Finds and reserves the best screen position for a surface.

The resulting position is registered under surfaceName so that subsequent placement requests consider the new surface occupied.

Returns
std::nullopt if no suitable position is available, otherwise the position the surface should be placed at.
