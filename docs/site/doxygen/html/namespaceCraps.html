Detailed Description

Craps Library (lib-craps)

This library is the Craps engine. It is the "Model" in the Model/View/Controller (MVC) design paradigm.

  • Contains no threads
  • Calls into the Controller to obtain configuration info
  • Publishes events
  • Knows nothing about any CUI/GUI
  • Read/writes files containing game configuration and stats
